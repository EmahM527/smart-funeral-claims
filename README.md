# Smart Funeral Claims Platform

A web-based system to automate and streamline the funeral insurance claims process. Built with Node.js, Firebase, and EmailJS.

## Features
- User registration/login (secure, validated)
- Digital claim submission & document upload
- Real-time claim tracking
- Admin dashboard for claims & user management
- Contact form (EmailJS)
- Modern blue & white responsive design

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js (Express)
- Database: Firebase (Firestore, Auth, Storage)
- Email: EmailJS

## Folders
- `/public` - Main website frontend
- `/src` - Backend (Node.js/Express)
- `/admin` - Admin portal
- `/diagrams` - System diagrams (UML, DFD, ERD)

## Setup
1. Clone repo
2. Install dependencies (`npm install` in `/src` and `/admin` if needed)
3. Configure Firebase & EmailJS
4. Run backend: `npm start` in `/src`
5. Open `/public/index.html` for main site
6. Open `/admin/index.html` for admin portal
